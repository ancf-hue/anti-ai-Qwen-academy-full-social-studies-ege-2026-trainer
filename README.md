📚 Анти-ИИ Квен Академия | Полный тренажёр ЕГЭ-2026 по обществознанию
English: Anti-AI Qwen Academy | Full Social Studies EGE-2026 Trainer
Бесплатный, автономный HTML-тренажёр для подготовки к ЕГЭ по обществознанию 2026 года. Работает без интернета, без регистрации и без рекламы. Поддерживает переключение интерфейса между русским (RU) и английским (EN) языками.


🌐 Двуязычность (RU/EN): Полная локализация всех заданий, пояснений и интерфейса. Идеально подходит для международных школ и студентов, изучающих русский язык.

⏱️ Экзаменационный таймер: Встроенный секундомер с пресетами:
Экзамен: 210 минут (формат ЕГЭ-2026).
Тренировка: 60 минут.
Визуальные предупреждения при истечении времени.

📚 25 Заданий (Часть 1 + Часть 2):
Часть 1 (16 заданий): Тестовые вопросы с выбором ответа по всем блокам кодификатора (Человек и общество, Экономика, Социальные отношения, Политика, Право). Варианты ответов перемешиваются случайно.
Часть 2 (9 заданий): Развёрнутые ответы с методическими подсказками, эталонами и полями для самопроверки. Охватывает работу с текстом, экономические и правовые задачи, сложные планы и примеры.

🔒 Полная автономность: Один HTML-файл. Не требует установки Python, Node.js или подключения к серверам. Работает прямо из браузера (file:///).

🛡️ Anti-AI Approach: Задания составлены так, чтобы проверять глубокое понимание концепций, а не просто поиск ответа в интернете. Включены подробные объяснения ошибок и типичных ловушек ФИПИ.

✅ Чек-лист и План подготовки: Интерактивный чек-лист из 21 пункта и детальный план занятий на 25 дней для системной подготовки.
